G3 移植结果

视频组输入：G1 源码 + G2 的 clean 视频 + 任务说明（含对话期间暂停战斗等约定）。文字组：同样的 G1 源码和任务说明，视频换成一段文字（宝可梦式像素对话的描述 + 说话者和全部台词，没有任何数值和画面）。每个 agent 在隔离沙箱里一次写完，看不到 G2 / G3 源码和隐藏测试。评测：9 段隐藏输入在 GT G3 和候选上逐 tick 回放，比较射击状态、对话观测、战斗事件和画面。

画面：逐帧平均像素差 < 1.5（0–255）算一致；均差是 9 段的平均。完全一致 = 每个 tick 的射击状态、对话观测、战斗事件都和 GT 相同。

事后补充诊断（不在 9 段隐藏输入里）：选项框里按 ↓ ↓ ↑ ↑ ↑，GT 到头停住（1 1 0 0 0），Opus 和 astra 都是循环（1 0 1 0 1）。G2 clean 视频里第二次 ↓ 按在边界上、画面不变，所以只看 clean 视频推不出这条规则。
