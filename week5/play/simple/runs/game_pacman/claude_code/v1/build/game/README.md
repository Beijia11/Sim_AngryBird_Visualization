Pac-Man style maze chase: pac-man runs the corridors eating pellets, eats the top-left power pellet, and the patrolling ghost flees frightened.
Controls: arrow keys / WASD choose the next turn (pac-man keeps moving until blocked).
Approximate: maze wall rectangles, pellet placement, speeds (~115 px/s pac, ~97 px/s ghost) and ghost AI (top-corridor patrol only).
