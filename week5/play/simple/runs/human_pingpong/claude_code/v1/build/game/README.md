Simulates a table tennis rally from a static high camera: near player (controlled) vs far player (AI auto-return), a ball with gravity and table bounces, two seated umpires.
Controls: Left/Right (a/d) to move the near player, Space to swing (serve, then return), q/e to aim the return.
Approximate: ball physics are in screen space with a fake height, racket is a short segment, poses are looped clips from the video, regions are rough polygons.
