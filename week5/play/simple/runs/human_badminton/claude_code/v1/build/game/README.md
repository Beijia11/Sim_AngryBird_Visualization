Simulates a badminton singles rally on a static broadcast view: near player (controlled), far player (AI that chases and returns), shuttle flying in arcs between them.
Controls: drag/click to run the near player to a court position; Space to swing (returns the shuttle when it is arriving within reach).
Approximate: fixed 1.05 s flight time, scripted landing targets, swing pose clips taken from the video, court/net geometry eyeballed from frames.
