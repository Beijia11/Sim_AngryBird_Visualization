Simulates a robot arm on a table repeatedly picking up a small box and placing it elsewhere (2-link IK arm, parallel gripper, box held/released and settles on the table).
Controls: drag/click to send the gripper to a point, arrow keys/WASD to nudge it, Space to close/open the gripper.
Approximate: arm geometry, table layout and pick/place positions and timings are eyeballed from the clip; perspective/depth is ignored.
