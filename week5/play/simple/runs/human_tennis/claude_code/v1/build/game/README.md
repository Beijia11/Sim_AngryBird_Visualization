Simulates a tennis rally from a fixed broadcast view: you control the near player, the far player is a built-in opponent, and the ball flies on screen-space arcs.
Controls: arrows/WASD to move, drag to run to a point (move), drag to swing and aim (swing).
Approximate: the ball uses 2D screen gravity with no bounce, the opponent follows a fixed shot plan, and poses are clips taken from the video.
